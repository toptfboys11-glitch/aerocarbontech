# Application Page Template

## Planning

- Objective, intent, audience, buyer stage, application scope and indexation status:

## Required Original Information

- Application requirements and material-selection considerations.
- Relevant products and processes.
- Constraints, buyer inputs and validation questions.
- Civil/commercial/industrial context only; no implied past deployment.

## Required Images

- Licensed application context and original relevant parts. Do not present stock imagery as a customer project.

## Suggested Structure

1. H1: `Carbon Fiber [Products/Parts] for [Application]`
2. Application needs.
3. Relevant product choices.
4. Design/manufacturing considerations.
5. Quality and validation questions.
6. Procurement/RFQ inputs.
7. Related technical guide and CTA.

## Links / CTA

- Applications pillar; product pillar; capability; technical guide; `/\#contact`.
- CTA: `Discuss Your Application`.

## Schema

BreadcrumbList; no Product/Service schema without supporting facts.

## Indexation / Business Verification

- [ ] Distinct useful application content.
- [ ] Product/process suitability reviewed.
- [ ] No doorway/regional duplication.
- [ ] Metadata/canonical/H1/links pass QA.

## Legal / Factual Accuracy

- [ ] No customer, mission, performance, safety or operational claim without evidence.
- [ ] No military, weapon, targeting or combat content.
